Este repositorio está organizado meticulosamente en categorías para facilitar su exploración.

---

## 📂 Estructura del Repositorio

### 🧠 [Machine Learning & Deep Learning](./Machine_Learning_Deep_Learning/)
Proyectos enfocados en la inteligencia artificial, modelos predictivos y redes neuronales.
- **Agente_Investigador_GenAI**: *[GEN-AI & AGENTES]* Agente Inteligente autónomo usando LangChain y Tool Calling para investigar en internet en tiempo real y resumir resultados.
- **Prediccion_Fuga_Clientes_End_to_End**: *[PROYECTO COMPLETO]* Pipeline completo de Machine Learning (Preprocesamiento, GridSearchCV, Random Forest) para predecir el Churn.
- **Clasificacion de Perritos**: Modelo de visión artificial basado en redes neuronales para clasificar razas caninas.
- **Red PLN**: Procesamiento de Lenguaje Natural para el análisis e interpretación de secuencias textuales.
- **Texto a Modelo de OpenAI (Point-E)**: Integración con la API de OpenAI para el uso de modelos generativos de Point-E.
- **Primera Red Neuronal**: Implementación inicial de una arquitectura de redes neuronales profundas usando TensorFlow.

### 🛡️ [Ciberseguridad & APIs](./Ciberseguridad/)
Scripts y experimentaciones orientadas a la seguridad de la información.
- **API VirusTotal**: Interacción con la API de VirusTotal para el análisis automatizado de archivos y URLs en busca de malware.
- **HASH**: Técnicas de criptografía, hashing de contraseñas y aseguramiento de integridad de datos.

### 🎮 [Juegos y Desarrollo Web](./Juegos_y_Desarrollo_Web/)
Proyectos interactivos, desarrollo frotend y lógica de juegos.
- **Página Web Juegos**: Proyecto de desarrollo frontend implementando estándares web.
- **Tetris**: Clásico juego de Tetris programado y estructurado con lógica de videojuegos.
- **Sudoku**: Implementación computacional del famoso juego de números.

### 📊 [Web Scraping y Análisis de Datos](./Web_Scraping_Analisis_Datos/)
- **Web Scraping**: Extracción automatizada, transformación y limpieza de datos provenientes de la web.

### 🖼️ [Procesamiento de Imágenes](./Procesamiento_Imagenes/)
- **Editor de Fotos con Python**: Herramienta de procesamiento digital de imágenes con capacidad de aplicar filtros e interacciones matemáticas sobre píxeles.
